# Gimersia Game Jam - AI Vibe Coding Template

Dokumentasi dan panduan context engineering untuk kolaborasi bersama AI assistant (Cursor, GitHub Copilot, Claude Code, dll.) selama event Gimersia (9 - 29 November 2026).

## Struktur Repositori & Docs
- `RULES.md` / `.cursorrules`: Ruleset inti dan guardrails coding AI (termasuk aturan kepatuhan Gimersia).
- `docs/GDD.md`: Game Design Document (Core loop, elevator pitch, target platform, kontrol).
- `docs/TECH_STACK.md`: Arsitektur engine, dependencies, bahasa, dan hierarki folder.
- `docs/SPRINT.md`: Roadmap milestone 3 minggu dan checklist harian.
- `docs/ASSET_MANIFEST.md`: Log deklarasi lisensi & atribusi aset 3rd party (Wajib Gimersia).
- `docs/CORE_MECHANICS.md`: Parameter numerik & kalkulasi mekanik spesifik.
- `docs/UI_FLOW.md`: State machine transisi navigasi antarmuka/scene.
- `docs/KNOWN_ISSUES.md`: Issue & bug tracking aktif.
- `docs/CHANGELOG.md`: Log iterasi dan update versi build.

## Cara Menggunakan
1. Taruh `RULES.md` dan `.cursorrules` di root workspace IDE Anda.
2. Isi `docs/GDD.md` dan `docs/TECH_STACK.md` segera setelah tema kompetisi diumumkan.
3. Selalu perbarui `docs/ASSET_MANIFEST.md` setiap kali mengimpor aset eksternal.
